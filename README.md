# CloudPulse MVP

AI Athletic Coaching Agent for Samsung Solve for Tomorrow competition.

**Team:** Riga State Gymnasium N3.  
**Category:** Sports & Technology

## Quick Links
- [Product Specification](./CloudPulse_Product_Spec.md)
- [System Prompt for Claude API](./CLAUDE_SYSTEM_PROMPT.md)

## Overview
CloudPulse is an adaptive AI coaching agent that builds personalized training 
plans for students, without focusing on weight or body metrics. The MVP includes 
conversational onboarding, dynamic weekly plans, and safety guardrails.

## Tech Stack
- Frontend: Next.js + Vercel
- AI: Claude API (Anthropic)
- Database: Supabase
- Styling: Tailwind CSS

## Status
Currently in MVP development for 1 Stage submission (deadline 16.10.2026).
